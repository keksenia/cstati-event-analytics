# cstati Event Analytics

Проект по продуктовой аналитике портфеля мероприятий **cstati** — студенческой организации ФКН ВШЭ.

Я анализирую, как студенты взаимодействуют с мероприятиями cstati: какие события приводят новую аудиторию, какие помогают удерживать участников, как люди переходят между форматами мероприятий и какие решения могут улучшить event-стратегию.

Публичная версия репозитория содержит только обезличенные и агрегированные результаты. Исходные регистрационные данные и персональная информация участников не публикуются.

---

## Зачем нужен проект

cstati проводит офлайн-мероприятия для студентов. У разных событий разные продуктовые роли: одни помогают привлекать новых участников, другие удерживают уже знакомую аудиторию, третьи работают на вовлечение и формирование сообщества.

Цель проекта — превратить разрозненные данные о регистрациях и посещениях в аналитическую систему, которая помогает отвечать на три вопроса:

1. Какие мероприятия лучше всего привлекают новую аудиторию?
2. Какие форматы помогают возвращать участников?
3. Что можно изменить в планировании, коммуникации и пост-ивент активации, чтобы увеличить вовлечение?

---

## Что было сделано

- Проведён аудит исходных данных и выявлены проблемы качества.
- Построен clean identity layer для анализа повторных участников.
- Рассчитаны event-level и portfolio-level метрики.
- Проанализированы новые и повторные участники, event families, глубина повторного участия и переходы между форматами.
- Собран Streamlit-dashboard для исследования портфеля мероприятий.
- Сформулированы продуктовые рекомендации для event-стратегии cstati.

---

## Ключевые результаты

- Проанализирован портфель из 18 офлайн-мероприятий.
- Построен privacy-aware пайплайн для анализа повторных участников без публикации персональных данных.
- Мероприятия разделены по продуктовой роли: привлечение, удержание, смешанные и нишевые форматы.
- Найдены точки, где портфель теряет потенциальных повторных участников после первого контакта.
- Подготовлены рекомендации по post-event activation, качеству регистрационных данных и проектированию event journey.

## Основные продуктовые вопросы

### 1. Привлечение аудитории

Какие мероприятия приводят больше всего новых участников?

Основные метрики:

- `new_participants`
- `new_share`
- `clean_participants`
- `event_family`
- `target_audience`

---

### 2. Удержание аудитории

Какие мероприятия и форматы помогают людям возвращаться?

Основные метрики:

- `repeat_participants`
- `repeat_share`
- `multi_event_share`
- `first_event_retention_proxy`
- `repeat_depth`

---

### 3. Переходы между мероприятиями

Как участники двигаются между форматами?

Основные метрики:

- `source_event`
- `next_event`
- `transition_count`
- `transition_rate`
- `family_to_family_transition`

---

### 4. Качество данных

Можно ли использовать данные для принятия решений?

Основные метрики:

- `clean_coverage_share`
- `strong_identifier_share`
- `identity_conflict_rate`
- `usable_records_share`
