# Методология проекта

## Цель

Проект анализирует портфель мероприятий cstati как event-community product: через рост аудитории, удержание участников, повторные посещения и качество вовлечения.

## Источники данных

В проекте используются три типа источников:

1. `Сводная.csv` — backbone-источник для связи `event × participant`.
2. Отдельные raw CSV по мероприятиям — источник event-specific полей: регистрация, оплата, посещение, сегменты.
3. `Мероприятия.csv` — архивный wide-dump, используется только как fallback для аудита.

## Ручные справочники

- `manual/event_metadata.csv` — справочник событий.
- `manual/event_aliases.csv` — сопоставление raw-названий с canonical event id.
- `manual/attendance_corrections.csv` — ручные корректировки известных проблем данных.

## Data quality

На этапе первичного аудита обнаружены:

- дубли строк в части источников;
- пустые колонки в отдельных raw-файлах;
- различия между raw-файлами и сводной таблицей;
- известная недооценка attendance для `Антипосвят'25`.

Эти проблемы не удаляются молча: они фиксируются как `quality_flags` и учитываются в следующих слоях обработки.

## Privacy

Raw-файлы с персональными данными не публикуются. Для анализа retention и journeys персональные идентификаторы используются только во внутреннем private layer.
