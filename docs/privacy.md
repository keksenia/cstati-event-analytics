# Privacy Policy for the Project
Проект работает с регистрационными данными участников мероприятий, поэтому raw-данные не публикуются в репозитории.
## Что не публикуется
- ФИО участников;
- Telegram;
- телефоны;
- email;
- raw CSV-файлы;
- private identity layer;
- intermediate private tables.
## Что может публиковаться
- агрегированные метрики;
- обезличенные event-level таблицы;
- графики;
- методология;
- код обработки;
- synthetic/sample data.
## Подход к идентификации
Персональные идентификаторы используются только локально для дедупликации и построения retention/journey-метрик. В публичные outputs попадают только агрегированные результаты.
